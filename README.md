# LaundryPro SaaS - Vue 3 PWA POS

Sistem Point of Sales (POS) dan manajemen cabang laundry modern, dirancang sebagai Multi-Tenant SaaS. Proyek ini dibangun sepenuhnya menggunakan Vue 3, Vite, dan Supabase.

## Fitur Unggulan
* Zero-Typing UI untuk Staf lapangan.
* Struk PDF yang dikirim otomatis via wa.me (Tanpa API).
* Pencetakan Label Printer Thermal via Web Bluetooth.

## Instruksi AI Agent (Jules)
Seluruh proyek dijalankan secara otonom oleh agen AI. Tolong baca instruksi khusus di file `AGENTS.md` sebelum memulai penulisan Single File Components (SFC).
