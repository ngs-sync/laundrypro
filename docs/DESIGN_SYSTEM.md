# UI/UX Design System

* **Warna Utama (Primary):** Emerald Green (`#10B981`) - Kesan bersih & sukses.
* **Warna Bahaya (Danger):** Rose (`#F43F5E`) - Untuk peringatan dan pembatalan transaksi.
* **Background:** Slate 50 (`#F8FAFC`) - Minimalis.
* **Typography:** Inter atau Roboto (San-serif, bersih, mudah dibaca staf).

## Komponen Kunci (Vue Components)
* **PrimaryButton.vue:** Tombol sentuh ekstra besar, *full-width*, p-4, warna Emerald Green.
* **NumpadInput.vue:** Grid 3 kolom untuk penginputan angka cepat. Ukuran teks font-bold text-3xl.
