# Application Flow (User Journey)

## 1. Onboarding Pemilik (Tenant)
Daftar via Web -> Masa Trial 30 Hari Aktif -> Setup Harga -> Tambah Staf.

## 2. Operasional Kasir (Staf)
Buka Shift (Input Kas Awal) -> Terima Baju -> Timbang -> Pilih Paket -> Bayar -> Cetak Label Internal (Bluetooth) -> Generate PDF -> Kirim Struk via WA (wa.me) -> Tutup Shift (Audit Kas).

## 3. Superadmin (Pemilik SaaS)
Login Superadmin -> Lihat Direktori Toko -> Pantau Kuota Nota -> Kirim Invoice Tagihan (WA) -> Impersonate Toko (Jika ada komplain).
